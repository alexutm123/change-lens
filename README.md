# Change Lens

Показывает в VS Code, что именно изменилось в файле: добавленные строки зелёным, удалённые —
красным зачёркнутым «призраком», сверху кнопки **Оставить** и **Вернуть**. Работает локально,
без запросов к ИИ, без ключей и настроек.

Подходит для любого агента, который правит файлы: DeepSeek Harness, Claude Code, Cursor, Codex,
скриптов и генераторов. Изменения, сделанные git, не подсвечиваются.

```
 3    <div>{!! $message !!}</div>                    ⌫ удалено (красным, зачёркнуто)
 ✓ Оставить   ⟲ Вернуть   ⇆ Дифф
 4 +  <div class="hint">
 5 +      Проверьте домен в личном кабинете.
 6 +  </div>
```

## Установка

Нужен только VS Code **1.90 или новее**. Ни Node.js, ни npm, ни аккаунт DeepSeek — ничего.

1. Скачать `change-lens-0.5.0.vsix` (из папки `dist/` или из Releases).
2. `Ctrl+Shift+P` → **Extensions: Install from VSIX…** → выбрать файл.
3. Перезапустить окно: `Ctrl+Shift+P` → **Developer: Reload Window**.

Готово. В правом нижнем углу появится `✦ Change Lens`.

## Как пользоваться

1. Открыть проект в VS Code **папкой** (не отдельным файлом).
2. Работать с агентом как обычно — он правит файлы.
3. В VS Code подсветятся изменённые строки, в статус-баре появится `⑂ Change Lens · N`.

| Действие | Как |
| --- | --- |
| Список изменённых файлов | `Ctrl+Alt+Shift+D` или клик по `⑂ Change Lens` |
| Оставить изменение | `Ctrl+Alt+Enter` |
| Вернуть файл как было | `Ctrl+Alt+Backspace` |
| Полный дифф в отдельной вкладке | кнопка **Дифф** над блоком |
| Лог расширения | `Ctrl+Shift+P` → **Change Lens: Показать лог** |

**`✦ Change Lens`** в статус-баре — просто индикатор: `✦` — изменений нет, `⑂` — есть.

## Что важно знать

- **Снимок делается при запуске VS Code.** Что изменилось до запуска редактора — сравнивать не с чем.
  Порядок: открыл VS Code → потом работаешь в агенте.
- **Файл должен быть открыт**, чтобы подсветка была видна сразу. Иначе изменение попадёт в счётчик
  в статус-баре, а подсветка появится при открытии файла.
- **Настоящие красные строки** стороннему расширению VS Code нарисовать нельзя — это внутренний API
  Copilot. Поэтому удалённое показывается «призраком», а полный дифф открывается кнопкой **Дифф**.
- Не отслеживаются: `node_modules`, `vendor`, `storage`, `dist`, `build`, `.git` и подобные каталоги,
  файлы больше 512 КБ и двоичные.
- **Git не подсвечивается:** пока git трогает свой каталог (признак `pull`, `checkout`, `merge`,
  `rebase`, `stash`), изменения считаются чужими — снимок просто обновляется. Через 5 секунд тишины
  подсветка снова работает.
- Если вы сами правите или сохраняете файл — изменение считается принятым, подсветка снимается.
