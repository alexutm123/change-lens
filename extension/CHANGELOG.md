# Changelog

## 0.5.0

- Расширение переименовано: **Change Lens** (было «DeepSeek Harness — Inline Diff»).
- Новый идентификатор пакета: `pilich.change-lens`, команды `changeLens.*`, статус-бар `✦ Change Lens`.
- Упор на универсальность: работает с любым агентом и любым инструментом, который пишет файлы.
- Старую версию `deepseek-harness.dsh-inline-edit` нужно удалить — иначе будут работать два расширения сразу.

## 0.4.0

- Изменения, сделанные git (`pull`, `checkout`, `merge`, `rebase`, `stash` и т.п.), больше не подсвечиваются.
  Признак — обращения git к своему служебному каталогу `.git`; в это время снимок просто обновляется.
- Через 5 секунд тишины в `.git` подсветка снова работает как обычно.

## 0.3.0

- Убрано всё лишнее: команда «изменить код через DeepSeek», ключи, настройки модели.
- Осталось одно: подсветка изменений, которые DeepSeek Harness вносит в файлы на диске.
- Кнопки «Оставить / Вернуть / Дифф», статус-бар со счётчиком файлов, список изменений.

## 0.2.0

- Подсветка правок, сделанных Harness: снимки файлов при запуске и локальный дифф.
- Кнопки «Оставить / Вернуть / Дифф», статус-бар, список изменённых файлов.

## 0.1.0

- Первая версия: inline-правка выделенного фрагмента через DeepSeek API (убрана в 0.3.0).
